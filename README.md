# 224 Days to Code

Hi! This is my public learning diary. For **32 weeks (224 days)** I am learning to code every single day — **Data Structures & Algorithms in Python** in the morning, and **Web Development** at night. Everything I learn goes into this repo, one folder per day.

I am starting from absolute zero. If you are also starting from zero, this repo is for you. The notes are written in simple English, like a friend explaining things over a cup of chai — no heavy jargon, and every concept is explained with everyday examples (train coaches, cricket, UPI, dabbawalas) so it actually sticks.

## Why this repo might help you

- **Zero to hero, in order.** Day 1 starts with "what is a variable". Nothing is skipped, nothing is assumed.
- **Real solved code.** Every problem I practise is in `main.py` — my actual code, including my mistakes and pending problems.
- **Line-by-line explanations.** Each day's `notes.ipynb` walks through the code line by line with dry-run traces, so you can see *why* it works, not just *that* it works.
- **Readable revision notes.** Each day's `notes.md` is the theory in plain words — perfect for quick revision before an interview.
- **Web dev from scratch too.** The night sessions build up HTML (then CSS, JS and beyond) step by step, with the same simple explanations.

## How each day is organised

```
Day-XX/
├── task.md            → today's tasks — ATTEMPT THESE FIRST
├── DSA/
│   ├── main.py        → problems I solved that day (my practice code)
│   ├── notes.md       → the day's concepts in plain English
│   └── notes.ipynb    → line-by-line walkthrough of the code
└── dev/
    ├── index.html     → what I built that night
    └── notes.md       → the night session's concepts
```

## How to use this repo

1. Open the day's `task.md` and **attempt everything yourself first** — no peeking.
2. Then read `DSA/notes.md` — it builds the concept from zero and fills your gaps.
3. Compare your solutions with `main.py`. Stuck on a line? Open `notes.ipynb` — every line is explained with a trace.
4. Doing web dev? Same order: `task.md` → build it → `dev/notes.md`.
